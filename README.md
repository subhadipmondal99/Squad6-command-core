## ⚡ Overview
**Squad Command Core** is a custom-built, futuristic dashboard designed to keep **Squad 6** motivated, organized, and hyper-focused during our intense Flutter Hackathon challenge. It serves as our central uplink, tracking the exact time elapsed since the team's formation and providing immediate access to our learning matrix.

## 🚀 Features
* **Live Temporal Tracking:** A precise, real-time counter tracking Days, Hours, Minutes, and Seconds since team formation (May 23, 2026).
* **Dynamic 3D UI/UX:** Features a mouse-tracking 3D arc effect, responsive hover states, and immersive glassmorphism styling.
* **Glitch & Typewriter Engines:** Custom-coded glitch text animations and a responsive JavaScript typewriter alert system for an authentic terminal aesthetic.
* **Interactive Particle Background:** Powered by `particles.js` to create a live, constellation-style digital environment.
* **Fully Responsive:** Engineered to flawlessly transition from desktop command centers to mobile smartphone viewports.

## 🛠️ Tech Stack
This project was intentionally built using core web technologies for maximum performance and zero bloat:
* **HTML5:** Semantic structure and layout.
* **CSS3:** Advanced animations (keyframes), CSS Grid/Flexbox, 3D transforms, and custom properties.
* **Vanilla JavaScript:** Time calculation logic, custom typing engine, and dynamic DOM manipulation.
* **External Libraries:** `particles.js` (for background effects).
* **Deployment:** Hosted seamlessly via [Vercel](https://vercel.com).
